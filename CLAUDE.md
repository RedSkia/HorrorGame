## Commands
- `build.cmd` = fresh web build + local nginx; `deploy.cmd` -> `deploy.ps1` = size check + `npx wrangler pages deploy HorrorGame/Builds/Web --project-name horrorgame --branch main`, credentials CLOUDFLARE_ACCOUNT_ID/CLOUDFLARE_API_TOKEN from Windows Credential Manager resource "HorrorGame Cloudflare" (asked once; `deploy.cmd reset`) (Cloudflare Pages, 25 MiB/file). WebGL-only importer overrides: textures max 1024, ambience/monster_growl Vorbis 0.45; Unity splash off.
- Unity MCP (`com.unity.ai.assistant`): Claude Code server `unity-mcp` -> `%USERPROFILE%/.unity/relay/relay_win.exe --mcp`; Unity must be open, approve under Project Settings > AI > Unity MCP Server.
- Headless import/compile check (Unity must be closed):
  `"C:/Program Files/Unity/Hub/Editor/6000.3.27f1/Editor/Unity.exe" -batchmode -quit -nographics -projectPath "C:/Users/marcu/HorrorGame/HorrorGame" -logFile <log>` then grep `error CS|Aborting`.

## Code rules
- As simple as possible, but clean. No abstractions "just in case".
- One responsibility per script. Balance numbers in ScriptableObjects (`Scripts/Data`); feel/visual/technical constants as named consts in the script that uses them.
- Events via `GameEvents`; only `GameManager` is a singleton; references wired in the Inspector.
- No namespaces. Input via `InputActionReference` fields.
- Move/rename assets together with their `.meta` (keep GUIDs).

## Git
- Only `develop` and `main`. Commit on `develop`, merge to `main`. No staging, no feature/fix branches.
